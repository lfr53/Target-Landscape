# Reference target set for calibrating the competitive-density bands.
#
#   python -m landscape --calibrate --out out/calibration
#
# The density score is only interpretable relative to other targets, so the
# band thresholds in config.py have to be derived from a spread that actually
# covers the range. This file is that spread. Each target is annotated with the
# band it ought to land in on prior knowledge — if a run puts a target far from
# its annotation, either the thresholds or the retrieval is wrong, and the
# index page makes which one obvious.
#
# The annotations are expectations, not ground truth. Update them when the
# field moves, and record the date you last ran this.
#
# Last full run: NOT YET RUN — the bands currently in config.py were set by
# hand against a handful of targets. Running this set and recording the
# results is the honest version of that section.
