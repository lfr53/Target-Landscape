# Target Landscape

Look up a drug target and see what is in development against it — grouped by
what each asset does to the target rather than counted, with trial
terminations separated into science-driven and business-driven, and the
indications where the genetics are strong and nobody has gone.

Built from Open Targets (CC0), ChEMBL (CC BY-SA 3.0) and ClinicalTrials.gov
(US Government public domain).

**Investor / Scientist** switches which figures lead and which view opens
first. Nothing is hidden in either mode — a scientist needs the competitive
picture and an investor needs the mechanism.

Source and method: https://github.com/lfr53/Target-Landscape
