# deal comparables

No free, redistributable deal database exists, so this directory holds
hand-maintained CSVs. Point the tool at one with --deals.

Columns: date, acquirer, target_company, asset, mechanism, stage_at_deal,
upfront_usd_m, total_usd_m, territory, source_url

Always fill source_url. A deal figure without a source is not usable in a memo.
